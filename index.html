Ewwii

Ewwii is a lightweight, extensible, and easy-to-use widget system for building interactive widgets, status bars, and more on both Wayland and X11 quickly.

Get Started View on GitHub 
# Quick install
sh -c "$(curl -fsSL https://ewwii-sh.github.io/install.sh)"

Built for Performance & Flexibility

Everything you need to construct high-performance desktop widgets.

Extensive Plugin Support

Use plugins to extend or replace core components of Ewwii, including the configuration language.

Hot Reload

Instantly see changes during development without having to restart your app for fast iteration.

Simple Configuration

Use a simple yet fast configuration language with an intuitive syntax for building your widgets.

Ecosystem Tooling

An ecosystem of tools focused on extending core functionality and providing the best user experience.

Feather Weight

Extremely lightweight on memory and binary size with the only overhead being the GTK4 framework itself.

X11 + Wayland Compatibility

Seamlessly create widgets across both X11 and Wayland compositor environments with ease.

Extend Ewwii With Plugins!

Use community plugins to extend the capabilities of ewwii.

  • Featured Plugins
  • Yucky Ewwii
    Language

    Language plugin for bringing back the original 'yuck' configuration language from eww (elkowars wacky widgets) for people who enjoy lispy syntax and for those who want to port their configuration.

  • Jscore
    Language

    A JavaScript language plugin with a unique way of managing data. It supports importing and using nodejs dependencies, which make it a powerful option for users already familiar with JavaScript.

  • PreCSS
    Styling

    A CSS plugin with predefined set of CSS classes ready to be used directly from ewwii. It works with the user-defined colors and aims to save time by being convenient.
